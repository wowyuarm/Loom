# .scratch 工作规则

这个子树保存某个主题在推进期间的研究、方案、本地实施票和验收证据。它不定义当前行为、公开接口或稳定流程；那些以 `src/`、`test/`、真实运行状态和 `docs/` 为准。本文件只规定怎么在这里工作，目录索引见 [README.md](README.md)。

## 工作项结构

活跃主题一个目录 `.scratch/<topic>/`，其中 `README.md` 是唯一续接入口，必须覆盖五项：

- **Status**：当前状态，用 [triage-labels](../docs/agents/triage-labels.md) 的词（已收口的主题写 `resolved` 或直接移入 `archive/`）。
- **last-checked**：最后一次核对日期。
- **当前 frontier**：谁在做、下一步动什么、卡在哪。
- **完成条件**。
- **正式文档出口**：稳定结论最终进入哪个 `docs/` 文件或 ADR。

其余内容按需存在，不预建空目录：

```text
<topic>/
├── README.md      # 续接入口（上述五项）
├── map.md         # 尚未形成方案的大型探索的路线图
├── spec.md        # 讨论收敛后的决策快照，写一次，后续演化不改写
├── issues/        # 本地实施票，一票一文件，编号从 01 起按依赖排序
├── research/      # 调研与证据，只留值得重读的
└── rounds/YYYY-MM-DD-<slug>/   # 同一主题反复审查时按轮次保存
```

## 实施票骨架

```markdown
# NN — 标题

**What to build:** 完成后可演示的端到端行为（用户视角，不是分层任务清单）
**Blocked by:** 阻塞它的票，或「None — can start immediately」
**Status:** <triage 状态；验收后写 resolved>

- [ ] 验收条件 1
- [ ] 验收条件 2
```

- **垂直切片**：一票切一条窄而完整的路径（schema → 运行时 → 测试），完成时本身可验证；不按层横切分票。
- **自包含**：新上下文不读完整历史也能开工。少写具体文件路径和代码片段（会过期）；原型里决策密集的片段（状态机、类型形状）可以内联并注明来源。
- **frontier**：阻塞票全部完成的票构成 frontier，一次推进一张没有依赖的票；串行链自上而下走。
- **宽重构例外**：一次机械改动的爆炸半径覆盖全仓时，不硬塞进垂直切片，按 expand–contract 排序——先扩展（新旧并存）、分批迁移、再收缩（删掉旧形态）。

## 生命周期

- **收口一个主题**：关掉或删掉未完成的票 → 稳定结论写进 `docs/` 或 ADR → 删掉没有追溯价值的流程材料 → 把主题移进 `archive/`。
- **archive 是历史**：归档里的状态和术语只代表当时的语境，不覆盖当前实现；不要为了让它与新代码一致而改写归档。
- **临时产物**：日志、调试截图、下载物和测试输出不要提交进活跃主题或 archive。体积大且可重跑的原始材料（例如完整 transcript）放仓外，并在工作项 README 里记录指针——`loom-bench` 的 `archive.json` 就是这么做的。本地跑出来的脚本与结果放 `local/`，不进仓库。

## 活跃与归档

- `.scratch/<topic>/`：正在推进的主题。
- `.scratch/archive/<topic>/`：已收口主题的历史资料。
- `.scratch/local/<topic>/`：本机工作区，**不进版本控制**（`.gitignore` 忽略 `.scratch/local/`），也不在两个索引里登记。

只有前两个在 [README.md](README.md) 建立索引；主题移动时同步修正跨主题相对链接和仓库里引用它的脚本或检查配置。

**`local/` 放什么**：判断标准是「删掉它对下一个读仓库的人有没有损失」——有损失留前两处，没有就放这里。该放：跑出来的 harness 脚本与结果 JSON、transcript、性能/覆盖率 dump，以及依赖本机路径与环境的产物。不该放：结论与读法（主题 README、`research/`、`spec.md`、issue、验收证据）和会被别人引用的口径。同一个主题可以横跨两处：结论留在 `archive/`，脚本与数据放 `local/`，archive 的 README 里写一行说明它们在哪，但不写指向 `local/` 的相对链接。`local/` 沿用原来的目录名（如 `harness/`、`results/`），别人（包括未来的自己）才认得出。
